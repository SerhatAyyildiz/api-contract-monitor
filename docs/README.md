## Beklenen dosya

**`ornek-bildirim.png`** — GitHub Actions üzerinden gönderilmiş gerçek bir
Telegram bildiriminin ekran görüntüsü. Ana README'nin "Örnek bildirim"
bölümü bu dosyaya bağlanır.

Görsel eklenirken dikkat: ekran görüntüsünde bot adı veya sohbet bilgisi
dışında gizli bir bilgi (erişim anahtarı, kimlik numarası) görünmemelidir.
